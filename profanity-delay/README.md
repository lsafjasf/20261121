# profanity-delay — 直播审听延时器（回环模式）

一台广播级审听延时器：正常输出比输入晚 **7 秒**；按下删词键后用一段
**短交叉淡化**（等功率，80 ms）跨过操作者选择的区间；丢失的延时只在
**低能量片段**通过重复当前帧逐渐补回（默认速率上限 50%，静音 0.25 s
后才开始补）。声音电平与缓冲水位画在**同一条时间轴**上（CSV + SVG +
PNG）。

## 运行

```sh
cargo run --release -- demo out     # 脚本化回环演示 + 泄漏证明
cargo run --release -- live out     # 交互回环：[d] 删词  [q] 退出并出证
cargo test                          # 引擎与证明的单元/集成测试
```

## 工作原理

- `src/delay.rs` — 核心引擎。环形缓冲预填 7 s 静音（上线即满延时）。
  读头只前进不后退，因此被删区间在物理上不可能被再次读到——连续两次
  删词亦然（第二次删除的跳过量被钳制在当前水位之内）。
- 删词键：在读头处向前跳过 `dump_len`（默认 4 s，操作者可选），跳过
  区间两端做等功率交叉淡化，听感无缝。
- 补回：仅当读头处帧 RMS 低于阈值且已持续静音 0.25 s 时，按速率预算
  “保持”当前帧（重复输出一帧静音），水位随之回升，直到回到 7 s。
- `src/signal.rs` — 语音替代信号：12 bit FSK 标记（1800/2600 Hz，
  80 ms/符号，固定可识别图样），嵌入 48 kHz 输入中代替“违禁词”；
  Goertzel 检测器在 4 个符号相位下扫描，机器可判定其有无。

## 证明（demo 模式输出）

输入在 10.0 s 与 14.6 s 各嵌入一个标记，16.5 s 与 17.2 s 连续两次按
删词键。证明步骤对**写盘后的 WAV** 重新解码检测：

- 输入中检出 2 个标记，扬声器路径（`output.wav`）中检出 0 个；
- 水位全程 ≥ 0，最终回到 7.0 s ± 0.2；
- 补回帧全部落在低能量段（时间轴绿色阴影）。

产物（`out/`）：`input.wav`、`output.wav`、`timeline.csv`、
`timeline.svg`、`timeline.png`、`report.txt`。demo 证明失败时进程以
非零码退出。
